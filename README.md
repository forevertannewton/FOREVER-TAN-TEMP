# Forever Tan - Landing Page

A professional, fully responsive landing page for Forever Tan.

## Features

- 🎨 Modern, clean design with custom tan/gold color scheme
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Smooth scroll navigation with active state highlighting
- 🎯 Interactive elements with hover effects
- 📋 Contact form for user engagement
- 🎭 Smooth animations and transitions

## Sections

1. **Navigation** - Fixed header with smooth scroll links
2. **Hero** - Eye-catching welcome section with CTAs
3. **Features** - Showcase of key benefits
4. **About** - Company information
5. **Contact** - Form and contact information
6. **Footer** - Links and social media

## Quick Start

Simply open `index.html` in your web browser to view the landing page.

## Files

- `index.html` - Main HTML structure (230 lines)
- `styles.css` - All styling and responsive design (578 lines)
- `script.js` - Interactive features and animations (131 lines)

## Browser Support

Works on all modern browsers including Chrome, Firefox, Safari, and Edge.
